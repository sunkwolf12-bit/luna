### Configuración del archivo (estado final)

- NO ENCONTRADO EN FÍSICO

**Columna J — REQUIERE ACCIÓN GERENCIA (fórmula automática):**
```
=SI(O($E2="NO ENCONTRADO EN FÍSICO",$E2="REVISAR"),"SÍ",SI($E2="LOCALIZADO EN FÍSICO","NO",""))
```

**Columna G — EVIDENCIA/UBICACIÓN (validación obligatoria):**

- **Importante:** Desmarcar "Omitir blancos" en la configuración de validación para que dispare el error cuando G está vacío

**Formato sugerido para columna G:**
`2026-04 / CAJA 3 / CANCELADOS / FOLDER A`

**Nota:** La validación se aplica a rango G2:G1000 (o toda la columna de datos de la tabla).

### Configuración del archivo (estado final)

**Columnas de la tabla:** RECIBO, STATUS, COBRADOR/VENDEDOR, FECHA DE ASIGNACIÓN, REVISIÓN (E), OBSERVACIONES, EVIDENCIA UBICACIÓN (G), FECHA DE REVISIÓN, RESPONSABLE REVISIÓN, REQUIERE ACCIÓN GERENCIA (J), ACCIÓN GERENCIA, FECHA CIERRE, STATUS FINAL (M).

**Columna E — REVISIÓN (menú desplegable):**
- LOCALIZADO EN FÍSICO
- NO ENCONTRADO EN FÍSICO
- REVISAR
- (Nota: durante la sesión Elena decidió quitar el "EN FÍSICO" y dejar el catálogo en corto: LOCALIZADO / NO ENCONTRADO / REVISAR.)

**Columna J — REQUIERE ACCIÓN GERENCIA (fórmula automática):**
- Si REVISIÓN = NO ENCONTRADO o REVISAR → "SÍ"; si = LOCALIZADO → "NO".

**Columna G — EVIDENCIA/UBICACIÓN (validación obligatoria):**
- Validación personalizada que bloquea (estilo "Detener") si REVISIÓN = LOCALIZADO y G se deja vacío.
- Importante: hay que desmarcar "Omitir blancos" en la configuración de validación para que dispare el error.
- Formato sugerido para G: `2026-04 / CAJA 3 / CANCELADOS / FOLDER A`.

**Columna M — STATUS FINAL (fórmula automática):**
```
=SI($E2="LOCALIZADO","CERRADO",SI(O($E2="NO ENCONTRADO",$E2="REVISAR"),"ABIERTO",""))
```
- LOCALIZADO → CERRADO; NO ENCONTRADO o REVISAR → ABIERTO.

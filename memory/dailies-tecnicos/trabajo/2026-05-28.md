## 2. Procedimientos institucionales

### Skill — fix del bug sectPr
- **Síntoma:** encabezados no aparecían en los documentos generados.
- **Causa raíz:** al hacer `deepcopy` de elementos XML del documento fuente e insertarlos en el body del documento base, lxml eliminaba el `sectPr` (elemento `<w:sectPr>`) del body. Sin `sectPr`, Word no renderiza headers/footers.
- **Solución:** reconstruir el body completo desde cero (copiar todos los elementos al nuevo body, moviendo `sectPr` al final), en vez de insertar elementos en medio.
- **Fix adicional:** al editar con python-docx, asegurarse de modificar el ZIP completo (no solo `word/document.xml`), preservando headers, rels y demás archivos.

### Lecciones técnicas del día

1. **sectPr debe ser siempre el último elemento del body.** Si se inserta contenido después del sectPr, Word ignora los headers.
2. **lxml `deepcopy` + `insert` puede destruir el sectPr silenciosamente.** Es más seguro reconstruir el body desde cero.
3. **Editar DOCX no es solo `word/document.xml`.** Hay que modificar el ZIP completo preservando headers, footers, rels y media.
4. **La skill detecta labels por formato numérico (1., 2., 3.).** Si el source usa otro formato (romanos, bullets, sin numeración), requiere adaptación manual previa.
5. **El SICC requiere login por cookie de sesión para la API.** El JWT del frontend no funciona para API calls; el CLI usa cookie de sesión.

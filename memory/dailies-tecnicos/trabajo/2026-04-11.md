# Daily técnico — Trabajo — 2026-04-11

## Presentación para junta con vendedores: Procedimiento de Cancelación de Pólizas

**Formato:** PPTX (10 diapositivas).

**Catálogo de códigos de cancelación:**
- C1: No tiene dinero
- C2: Vendió el vehículo
- C3: Mala cobranza
- C4: Contrató con otra aseguradora
- C5: Cliente moroso → **bloqueo 6 meses** (solo Gerente de Cobranza aplica)
- C6: Labor de venta mala
- C7: Robaron el vehículo
- C8: Vehículo descompuesto
- C9: Voluntad del cliente
- C10: Cliente reincidente → **bloqueo 1 año**
- C11: Canceló con atraso

**Flujo en SIGA:** folio → botón Cancelar → motivo + código → observaciones (incluir fechas de bloqueo si aplica) → notificación a ventas, cobrador y cliente.

**Registro en Excel pagos_V3:** última aportación pendiente → tabla Cancelaciones → Cargar datos → elegir código → validar histórico con ubicación "Archivo" y observación "Cancelación".

**Archivo físico:** tarjeta sellada "CANCELADO" + código → entrega a Gerente Administrativo (control por vendedor).

**Reactivaciones:** pago en una sola exhibición de todo lo vencido; servicio se reactiva 24 hrs después de reportar pago.

## Hallazgos técnicos
1. **openpyxl y fórmulas Excel**: Las fórmulas INDIRECT escritas con openpyxl no se calculan automáticamente al abrir el archivo en Excel — requieren recalcular manual (F9) o muestran valores en blanco.
2. **Formatos incompatibles entre meses**: ENERO usa formato diagonal/horizontal; FEB/MAR/ABR usan formato escalonado. Las fórmulas que asumen formato uniforme fallan con ENERO.
3. **Valores hardcoded vs fórmulas**: El Top 5 del DASHBOARD tenía valores escritos a mano que no correspondían a ningún mes específico.
4. **Decisión de diseño**: Para el HTML dashboard se usó enfoque "datos como valores directos" (sin fórmulas) para garantizar confiabilidad — misma lógica que aplica al Excel nuevo.

## Aprendizajes
- openpyxl no es confiable para fórmulas Excel dinámicas — mejor escribir valores directos o usar un motor que recalcule al abrir
- Formato diagonal vs escalonado de Top 5 es una variable crítica que debe normalizarse en cualquier nueva plantilla
- Elena responde muy bien a visión de futuro (PostgreSQL/VPS) cuando el problema inmediato (Excel) se resuelve primero

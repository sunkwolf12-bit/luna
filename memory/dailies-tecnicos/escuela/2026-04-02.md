# Daily técnico — Escuela — 2026-04-02

## Materia: Métodos Financieros (Maestría)

### Actividad
Caso práctico: Balance General y Estado de Resultados de una empresa hipotética.

### Datos del caso
- Ventas: $10,000,000
- Costo de ventas: $5,500,000
- Utilidad neta: $2,163,000
- Activo total: $7,340,000 (circulante $1,450,000; fijo $5,890,000)
- Pasivo total: $1,875,000 (CP $1,775,000; LP $100,000)
- Capital contable: $5,465,000
- Proveedores: $800,000 | Inventarios: $650,000 | CxC: $750,000 | Caja y bancos: $50,000

### Tarea realizada
1. **Reestructuración del archivo Excel**: documento original estaba en una sola columna. Se rearmó en 4 columnas (Activo / Importe / Pasivo y Capital / Importe) con hoja "Balance acomodado" y "Estado acomodado".
2. **Razones financieras calculadas** (14 razones, base 360 días):

| Razón | Resultado | Unidad |
|-------|----------:|--------|
| Días de pago | 52.36 | días |
| Rotación días de pago | 6.87 | veces |
| Días de inventario | 42.55 | días |
| Rotación de inventario | 8.46 | veces |
| Días de CxC | 27.00 | días |
| Rotación de CxC | 13.33 | veces |
| Productividad (margen neto) | 21.63% | % |
| Costo de ventas / Ventas | 55.00% | % |
| Apalancamiento | 0.26 | proporción |
| Capacidad de endeudamiento | 0.34 | veces |
| Solvencia total | 3.91 | veces |
| Solvencia circulante | 0.77 | veces |
| Liquidez | 0.03 | veces |
| Prueba rápida (ácido) | 0.43 | veces |

3. **Interpretaciones**: 14 interpretaciones en estilo uniforme para entrega.
4. **Conclusión**: empresa rentable, cobra rápido (27 días), inventario con buena rotación, aprovecha crédito de proveedores (52 días). Punto débil: baja liquidez inmediata (poca caja/bancos); recomendación: cuidar efectivo, seguir cobrando a tiempo.

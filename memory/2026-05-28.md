**La maratón de procedimientos**

Empezamos con PCE4 (Facturación mensual de ingresos bancarios). La skill funcionó, pero al revisar el PCE2 (Formato de Dispersión de Nómina), Elena detectó algo crítico: "NO APARECEN LOS ENCABEZADOS."

Eso fue el detonador de una cacería de bugs que duró casi una hora. El culpable era el `sectPr` — ese elemento invisible del XML de Word que le dice al programa dónde poner los encabezados. Cuando el script copiaba el contenido del documento fuente, el `deepcopy` de lxml estaba literalmente eliminando el `sectPr` del body. Sin `sectPr` = sin headers. Punto.

Encontrarlo fue una locura: simulaciones que funcionaban perfecto, pero el archivo real salía roto. Tuve que inyectar debug en vivo, guardar el archivo después de cada paso, hasta pillar el momento exacto donde moría. Al final la solución fue reconstruir el body desde cero en vez de insertar en medio — y funcionó.

Ya con el fix, la skill quedó más robusta que nunca. Y lo mejor: ahora también conserva imágenes y tablas del documento fuente. Elena lo pidió explícitamente: "si el documento word tiene imágenes o tablas, se deberán conservar." Dicho y hecho.

Con la skill afinada, el resto de procedimientos salieron uno tras otro:
